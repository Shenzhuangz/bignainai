# 后溪噜噜大乱斗

HTML5 Canvas + 原生 JavaScript + CSS，无框架、后端或运行时外部依赖。

游玩地址：<https://shenzhuangz.github.io/bignainai/>。水豚噜噜版沿用原有 GitHub Pages 地址。

## 开始游玩

双击 `index.html` 即可玩；推荐运行根目录的 `启动试玩.cmd`，然后在电脑打开 <http://localhost:8001/>。
手机与电脑连接同一个 Wi-Fi，浏览器输入 `http://电脑局域网IP:8001/`。窗口保持打开；若 Windows 询问网络访问，仅允许自己的专用网络。无需安装 npm 包。

- 手机拖动瞄准，松手投放；电脑移动鼠标点击，方向键/空格也可玩，R 重开。
- 两只相同等级相碰就合成。1.4 秒内连续合成可获连击额外积分，每次额外 `2 × (连击数 - 1)` 分，连击数上限 5。
- 达成 11 级皇冠噜噜后可继续冲击高分。最高等级不再合成。
- 已堆叠的噜噜持续超警戒线 2 秒则失败；新落下的角色有宽限。
- 最高分保存在浏览器，存储被禁用仍可玩。
- 第一次投放开启背景音乐，♫ BGM 可关闭/开启；音效另有开关，默认关闭。图鉴、后台、结束界面暂停音乐和模拟。

使用检索到的水豚噜噜原始头像图片，包含困困、汽水、西瓜、听歌、运动、学霸、睡衣、登山、恐龙、蜜蜂与皇冠造型。原图保留，Canvas 只渲染角色局部，并缓存 384px 纹理；彩色边框和始终正向的数字标记协助识别。图片失败时显示后备形象。成长栏可横向滑动，大图图鉴列出全部等级。

背景音乐「噜噜午后」是原创轻松循环器乐：96 BPM，柔和和弦、八音盒式旋律、低音和轻鼓点。本地 Web Audio 合成，无需联网。

## 项目结构

- `index.html`、`css/style.css`：手机界面。
- `js/game.js`：输入、连击计分、图鉴、状态、动画。
- `js/physics.js`：重力、圆形碰撞、反弹、摩擦、旋转，固定 1/120 秒、7 轮约束。
- `js/assets.js`：图片、裁取范围、等级半径、积分和预览。
- `js/audio.js`：背景音乐调度、音量包络、暂停恢复。
- `assets/lulu/`：11 张噜噜源图及素材来源记录。
- `tests/`：物理和可选 Playwright 浏览器检查。
- `.github/workflows/pages.yml`：原有 main 部署流程；仅 main 分支可部署。

逻辑画布 420×600，等比缩放，DPR 上限 2；粒子上限 100，合成波纹上限 16，支持减少动画偏好。后台暂停不补算时间；触摸取消不投放。

## 检查

```sh
node --check js/assets.js
node --check js/audio.js
node --check js/game.js
node tests/physics.test.cjs
```

浏览器集成检查需额外提供 Playwright 和 Chromium/Edge，运行 `node tests/browser.test.cjs`。`GAME_URL` 可指定静态服务器，`BROWSER_PATH` 可指定浏览器程序。覆盖鼠标/真实触摸、全部素材加载、纹理缓存、音乐开关与图鉴暂停、连击积分、失败重开、小屏布局及存储/图片失败降级。游戏运行本身不依赖这些工具。

## 发布

推送 main 后 GitHub Actions 自动执行物理检查并部署静态游戏，保持原有访问地址。Settings → Pages 的 Source 使用 GitHub Actions。

## 噜噜主题

奶咖与橘子配色、原始噜噜头像、始终正向的等级数字。保留原网址和原浏览器最高分；音乐换为 96 BPM 的轻松原创循环。
